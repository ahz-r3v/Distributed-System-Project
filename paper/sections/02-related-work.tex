\section{Background and Related Work}
\label{sec:related-work}

\paragraph{Prefix reuse and policy choices.}
Prefill computes KV state for an input prompt; decode extends it as tokens are generated.
A later request can reuse an unchanged, compatible prefix instead of repeating its prefill.
FCFS orders waiting requests by arrival, whereas prefix-aware scheduling favors requests needing fewer additional KV blocks.
LRU evicts by recency; CacheWise predictive eviction uses tool metadata to estimate when an inactive session will return~\cite{Tiwari2026CacheWise}.
These decisions interact because scheduling changes both cache residency and the time at which a prefix is needed.

\paragraph{Recovery across memory tiers.}
InferCept already chooses among GPU retention, CPU swapping, and recomputation during external interruptions~\cite{Abhyankar2024InferCept}.
CachedAttention extends reuse across GPU, host DRAM, and SSD storage, overlapping transfers with computation and using queue look-ahead for prefetching~\cite{Gao2024CachedAttention}.
LMCache provides an engine-independent KV layer with CPU, disk, and remote backends~\cite{Liu2025LMCache}.
Cake combines loading and recomputation rather than treating them as exclusive alternatives~\cite{Jin2025Cake}.
Our recovery model is a serial baseline for the implemented host path, not a general optimum over these mechanisms.
The Mini-SGLang extension uses page-level host residency and a request priority that discounts host hits.
Its evaluation fixes tier capacities for policy ablations, while the restoration-versus-recomputation comparison explicitly adds host memory.
