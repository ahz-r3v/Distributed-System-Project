## 记录建议

- 阅读笔记：原文链接、引用键、问题、方法、结论、局限及关键页码。
- 讨论记录：日期、参与者、议题、决定、待办与负责人。
- 实验记录：假设、代码版本、运行环境、参数、执行命令、原始数据位置与分析。
- 对暂未核实的信息明确标注，避免在正文中误写为既定事实。
